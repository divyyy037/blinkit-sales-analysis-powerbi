# 📊 Blinkit Sales Analysis (SQL + Power BI)

## 🚀 Project Overview
This project analyzes Blinkit retail sales data using SQL and Power BI to generate business insights and support data-driven decision-making.

## 🛠 Tools Used
- SQL (Data Cleaning & Transformation)
- Power BI (Dashboard & Visualization)
- Excel (Initial Data Handling)

## 📌 Key Features
- KPI tracking (Total Sales, Avg Rating, Orders)
- Category-wise performance analysis
- Outlet size & location analysis
- Regional sales trends
- Interactive dashboard with filters

## 📈 Insights
- Identified top-performing product categories
- Analyzed underperforming outlets
- Helped in inventory and sales optimization decisions
